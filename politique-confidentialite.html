Politique de confidentialité

Cette page explique quelles données peuvent être collectées via le site enasdigital.fr et comment elles sont utilisées.

Données collectées

Lorsque vous utilisez le formulaire de contact, les informations suivantes peuvent être collectées :

  • nom ou prénom renseigné dans le formulaire ;
  • adresse email ;
  • message envoyé ;
  • date d'envoi du message.

Finalité

Ces données servent uniquement à répondre à votre demande, préparer un éventuel devis et échanger au sujet de votre projet.

Base légale

Le traitement repose sur votre consentement lorsque vous envoyez volontairement un message via le formulaire ou par email.

Durée de conservation

Les messages peuvent être conservés jusqu'à 3 ans après le dernier échange, sauf demande de suppression de votre part.

Partage des données

Les données ne sont pas vendues. Elles peuvent transiter par les services techniques nécessaires au fonctionnement du site, par exemple l'hébergeur Render, Supabase pour l'authentification admin, ou Formspree si le formulaire de contact est activé.

Cookies

Le site n'utilise pas de cookies publicitaires. La page admin peut conserver une session technique Supabase pour maintenir la connexion de l'administrateur.

Vos droits

Vous pouvez demander l'accès, la rectification ou la suppression de vos données en écrivant à contact@enasdigital.fr.

Contact

Pour toute question liée à la confidentialité, contactez contact@enasdigital.fr.
